# DNSight

Python 3.10+ | SQLite | Streamlit | MIT License

DNSight — инструмент для автоматического сбора и анализа комплектующих ПК с DNS-Shop и PassMark. Рассчитывает метрику выгодности Benefit = Score / (Price × Price), ведёт историю цен, бенчмарков и выгодности, предоставляет дашборд и конфигуратор сборок.

## Возможности

- Парсинг DNS: категории, цены, технические характеристики (с поддержкой синонимов через spec_types).
- Парсинг PassMark: получение баллов производительности для CPU/GPU.
- Расчёт Benefit: Score / (Price²) — чем выше, тем выгоднее.
- Исторические данные: отслеживание динамики цен, скоров и выгодности во времени.
- Визуализация: интерактивные графики на Streamlit (Plotly).
- Конфигуратор ПК: подбор компонентов с максимальным Benefit под заданный бюджет.
- Гибкая БД: отдельные таблицы для каждого типа компонентов, полиморфные истории, поддержка миграций через Alembic.
- Автоматическое обновление: по расписанию (APScheduler или cron).

## Технологии

- Язык: Python 3.10+
- База данных: SQLite (возможен переход на PostgreSQL)
- ORM: SQLAlchemy 2.0
- Миграции: Alembic
- Парсинг: requests, BeautifulSoup4, cloudscraper (опционально)
- Веб-интерфейс: Streamlit, Plotly
- Планировщик: APScheduler

## Установка и запуск

1. Клонировать репозиторий:
   git clone https://github.com/yourusername/dnsight.git
   cd dnsight

2. Создать виртуальное окружение:
   python -m venv venv
   source venv/bin/activate      # Linux/Mac
   venv\Scripts\activate         # Windows

3. Установить зависимости:
   pip install -r requirements.txt

4. Настроить переменные окружения:
   скопировать .env.example в .env и при необходимости указать прокси или URL БД.

5. Инициализировать базу данных и применить миграции:
   alembic upgrade head

6. Заполнить справочники (типы компонентов, маппинг характеристик):
   python scripts/seed_data.py

7. Запустить обновление данных (вручную или в фоне):
   python run_updater.py --once      # однократно
   python run_updater.py             # запуск с планировщиком (каждые 6 часов)

8. Запустить веб-дашборд:
   streamlit run streamlit/dashboard.py

Дашборд будет доступен по адресу http://localhost:8501.

## Основные команды CLI

- python -m dnsight.cli init — инициализация БД (создание таблиц)
- python -m dnsight.cli add-component --type cpu --name "Intel i5-12400" --url ... — добавить компонент вручную
- python -m dnsight.cli update --type cpu — запустить обновление для конкретного типа

## Примеры использования

Дашборд:
- Главная страница: выбор типа компонента, просмотр текущей цены, скоры, Benefit.
- Графики истории: изменение цены, скоров и Benefit за время.
- Топ-10: компоненты с максимальным Benefit на текущий момент.
- Конфигуратор: задайте бюджет, получите список оптимальных деталей.

Конфигуратор (первая версия):
1. Выберите целевое назначение (игры, работа, универсал).
2. Укажите бюджет.
3. Система подберёт для каждого слота (CPU, GPU, RAM…) компонент с максимальным Benefit, укладывающийся в бюджет.

## Разработка

Добавление нового типа компонента:
- Создать новую таблицу в models.py (например, NVMeComponents).
- Добавить запись в component_types.
- Заполнить column_spec_mapping для характеристик.
- Обновить парсер DNS, добавив обработку нового типа.
- Создать миграцию Alembic: alembic revision --autogenerate -m "add nvme"

Запуск тестов (если будут):
pytest tests/
